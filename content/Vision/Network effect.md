Network effect describes a phenomena that value of system increases when more people participate.
The opposite case is that for system that don't have enough participants, it is harder to reach the critical mass.

Say we want to run PeerTube (see [[YouTube alternative done right]]). Problem is that there is no audience or more cinically say - *a traffic*. Authors are less likely to run their PeerTube (and even pay for it), because users are used to run YouTube or TikTok and see what's recommended.

And a recommendation system is the actual core product of apps like YT, TikTok, and even Instagram.

So one of core apps in our ecosystem should be [[Recommendation system]].
