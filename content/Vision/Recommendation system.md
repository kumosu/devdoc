Each [[VLOP]] has their own recommendation system (RecSys). It is *the main product* for the most of them actually.
But more importantly, RecSys are designed to achieve goals of their owners, not their users. All of them optimize on user retention, the ultimate goal of super-powered machine learning algorithms is "time-spent" not user satisfaction, and of course not long-term happiness of a user.

The only right form of RecSys is user-owned. The user-owned RecSys doesn't care how much time user spent on TikTok or YouTube, it cares if user is moving towards user-defined goals. If user wants to not stare in screen but get relevant news, it should carefully determine what news are really relevant.

### Different architecture

So architecture changes, instead of each platform has their RecSys, each user now has their own RecSys.

This changes a lot. In [[VLOP]], they put user's feature flags and content feature flags into a hyper-matrix, compute weights and determine what content will keep user on site.

User-owned RecSys should crawl web based on user data: what they explicitly marked as "subscribe to" (whatever it is a peertube channel or a static website), notes, tasks, current projects and future plans - whatever user allow for the RecSys to reach. 
This system can be very simple like RSS aggregator, or very complex as AI agent processing collected resources to build a digest.
